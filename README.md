KaushalSetu 

KaushalSetu is a mobile-first, multilingual platform designed to connect informal and semi-skilled workers—such as electricians, plumbers, mechanics, masons, carpenters, and service workers—with trusted local employment. Built for low-end smartphones, intermittent connectivity, and voice-friendly navigation, it enables workers without formal certification to convert real practical work into verified digital credentials while running their daily work with clear terms and dignity.

Key Features Voice-Friendly Onboarding & Proof: Simple voice or screen registration with photo and short video uploads to show real work evidence. AI Assist + Human Verification: AI organizes work proof against competency checklists and identifies skill gaps, while human assessors issue final verification statuses. Digital Skill Passport: Worker-controlled profile with QR and link sharing that clearly separates self-declared skills from assessor-verified skills. Hyperlocal Job Matching & Fair Pay: Transparent job recommendations showing trade, distance, schedule, and local fair-pay guidance. Day-to-Day Operations & Safety: Integrated work calendar, income and pending payment tracker with reminders, job safety checklists, trusted-contact check-ins, and guided complaint pathways. Tech Stack Frontend: React (mobile-first, responsive) Backend: Java Spring Boot (REST API) Database: PostgreSQL / MySQL Media & AI: Secure media storage with consent controls, speech-to-text, and skill evidence analysis Hackathon Prototype Scope
